# 📊 Student Marks Analysis using Python

A beginner-friendly Python project that analyses student marks and displays important statistics.

## 🎯 Project Overview

This project uses Python dictionaries and built-in functions to analyse student marks. It calculates total marks, average marks, highest marks, lowest marks, and displays each student's pass/fail result.

## 🛠️ Technologies Used

- Python
- Dictionaries
- Loops
- Conditional Statements
- Built-in Functions

## ✨ Features

- Display student names and marks.
- Calculate total marks.
- Calculate average marks.
- Find highest marks.
- Find lowest marks.
- Display PASS/FAIL results.

## ▶️ How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run this command:

```bash
python student_marks.py
```
